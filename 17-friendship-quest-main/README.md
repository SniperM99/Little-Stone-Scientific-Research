# friendship-quest

## 10关精简版

新增成品：`outputs/友爱奇旅-10关精简版.html`，浏览器打开即可离线使用。五章各两关，约25—30分钟；所有剧情互动只需点击一次，完成后直接显示“下一题”；点击后直接跳到下一道题。原15关版保留。配套主持词：`outputs/友爱奇旅-10关版主持词.md`。

10关版主持人为许牧宸，使用独立存档。配音统一采用与原15关版相同的晓晓普通话神经网络女声（zh-CN-XiaoxiaoNeural，语速 -8%），覆盖开场、五章故事、题目、答案、互动完成解说、通关承诺和辅助提示。支持自动配音、暂停、继续、停止与重听，所有音频已内嵌，可离线播放。保留单次点击互动、无闪光和章节介绍，不添加音效。

重建与检查（项目目录）：

```powershell
python work/build_ten_levels.py
node work/check_ten_levels.cjs
```

首次生成或更新10关配音时，先安装 `edge-tts`，再运行 `python work/build_ten_levels.py --generate-voice`。语音清单保存在 `work/ten_neural_manifest.json`，音频缓存按文案哈希命名。

友爱奇旅 · 一年三班合作闯关

一年级预防校园欺凌主题班会游戏。一人在讲台操作，全班举手回答，揭晓参考答案后由主持人判定，再共同完成章节互动。

直接使用浏览器打开 `outputs/友爱奇旅-微缩冒险闯关游戏.html`。图片及 52 段普通话 AI 配音已内嵌，可离线使用。语音支持情景与问题、只听问题、揭晓后朗读答案，以及暂停和停止。“自动朗读”为语音总开关，默认开启：游戏介绍、五章故事、题目、揭晓后的答案、互动解说与最终承诺均在对应环节自动播放；关闭后本机记住选择、可随手动按钮播放。浏览器若拦截首屏自动播放，点一下页面即会续播当前环节语音。

剧情互动包含离线合成音效、零件落位、飞机起飞、缆车移动及星光动画；音效可独立开关。每个互动动作在音效和动画之后自动播放自然语音解说，共 34 段；跟随自动朗读总开关，支持重听与停止，关闭互动窗口会停止解说。

电脑横屏下，主页面与互动弹窗自动适配窗口高度，完整显示问题、操作按钮和解说区域；窗口大小或全屏状态变化时会重新适配。

五章冒险：修木桥、拼积木飞机、守护纽扣森林、为缆车供电、建树屋看星星，共 15 个关卡。

## 构建与检查

在项目根目录运行：

```sh
python3 work/build_story_adventure.py
npm ci --prefix work
node work/check_story_adventure.cjs
node work/check_game_voice.cjs
node work/check_story_effects.cjs
node work/check_action_narration.cjs
```

制作脚本与音频清单保存在 `work/`，最终页面、素材及独立自然语音文件保存在 `outputs/`。

配音以系统旁白身份介绍游戏，不自称主持人。每关互动仅在完成时播放一段结果解说，不播放互动开始说明和“点击……”操作语音；点击“答对了”后会朗读页面上的“回答正确！获得……”奖励文字。

10关题目已按一年级理解能力重写：每次只问一件事，情景短、指向明确；参考答案提供一两句易说出口的示例，主持人只需判断是否表达了关键意思。文案源文件：`work/ten_level_copy.json`。
